SML Quick Guide

Standard ML Reference Sheet

1. Fundamentals

Standard ML uses immutable variable bindings declared with val. Values include integers, reals, booleans, characters, strings, tuples, and lists. 

val x = 5                        (* integer *)
val pi = 3.14                    (* real *)
val pair = (1, "hello")          (* tuple *)
val nums = [1, 2, 3]             (* list *)

Operators and Expressions

Arithmetic+ - * div mod / for reals
String concatenation"Hello, " ^ "world!"
Comparison= <> < > <= >=
Logicalandalso orelse not
Printingprint "Hello\n"
Type conversionInt.toString 5, Real.toString 3.0

Conditional Expression

Both branches of an if expression must have the same type.

val r = if x > 0 then "positive" else "non-positive"

2. Functions and Bindings

Function Definition

Named functions use fun. Anonymous functions use fn. Functions are first-class values. 

fun square x = x * x
val double = fn x => x * 2

Let and Local Bindings

let ... in ... end creates scoped bindings in an expression. local ... in ... end creates helper declarations visible only inside the block. 

(* let binding *)
val result = let val x = 3 in x + 2 end

(* local binding *)
local
  fun helper x = x + 1
in
  fun useHelper y = helper y * 2
end

Curried and Polymorphic Functions

fun add x y = x + y       (* curried *)
val addTwo = add 2        (* partial application *)
fun identity x = x        (* 'a -> 'a, polymorphic *)

3. Pattern Matching

SML matches values against patterns in function definitions and case expressions. The wildcard _ matches anything. 

(* Function pattern matching *)
fun describe 0 = "zero"
  | describe _ = "non-zero"

(* Case expression *)
val result = case x of
               0 => "zero"
             | 1 => "one"
             | _ => "other"

(* Nested conditionals *)
val r = if x > 0 then (if x > 10 then "big" else "small")
        else "negative"

4. Recursion

Recursion is the main looping mechanism in SML. Tail recursion is preferred because the compiler can optimize it into a loop.

Non-Tail vs. Tail Recursion

(* Non-tail: addition happens after recursive call *)
fun sum [] = 0
  | sum (x::xs) = x + sum xs

(* Tail-recursive: uses an accumulator *)
fun sum xs =
  let fun loop ([], acc) = acc
        | loop (x::xs, acc) = loop (xs, acc + x)
  in loop (xs, 0) end

Mutually Recursive Functions

fun isEven 0 = true
  | isEven n = isOdd (n - 1)
and isOdd 0 = false
  | isOdd n = isEven (n - 1)

5. Basis Library

The Standard Basis Library provides common modules such as List, String, Math, and IntInf.

String Processing

val chars = explode "hi"                (* [#"h", #"i"] *)
val str = implode [#"h", #"i"]         (* "hi" *)
val n = String.size "hello"            (* 5 *)
val s = String.substring ("hello", 1, 3) (* "ell" *)

List Operations

val mapped = List.map (fn x => x * 2) [1, 2, 3]      (* [2, 4, 6] *)
val evens = List.filter (fn x => x mod 2 = 0) [1, 2, 3, 4] (* [2, 4] *)
val rev = List.rev [1, 2, 3]                               (* [3, 2, 1] *)
val joined = [1, 2] @ [3, 4]                               (* [1, 2, 3, 4] *)
val len = List.length [1, 2, 3]                            (* 3 *)

Fold Operations

val sum = List.foldl (op +) 0 [1, 2, 3]        (* 6 *)
val s = List.foldr (op ^) "" ["a", "b", "c"]   (* "abc" *)

Math and IntInf

val sqrt2 = Math.sqrt 2.0
val big = IntInf.pow (IntInf.fromInt 2, 100)   (* arbitrary precision *)

6. Other Features

Exception Raising

raise Fail "error occurred"
exception MyError of string
raise MyError "something went wrong"

Custom Infix Operator

infix +-
fun x +- y = 2 * x - y
val result = 3 +- 1             (* 5 *)

Datatype Definition

datatype color = Red | Green | Blue
datatype shape = Circle of real
              | Rectangle of real * real

fun area (Circle r) = Math.pi * r * r
  | area (Rectangle (w, h)) = w * h
